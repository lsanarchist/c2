# v0.1 Backlog

## Реалізовано

- Базова HTTP взаємодія: check-in, видача команди, приймання результатів.
- Базовий CLI для `c2-server` та `c2-agent`.
- Поточні тести для основних сценаріїв агента й сервера.

## Заплановано

1. Auth/TLS
   - Явна авторизація агентів і операторів.
   - TLS для transport security на Linux/Windows.
2. Durable tasks
   - Надійне зберігання черги команд і результатів.
   - Відновлення стану після рестарту сервера.
3. Надійний агент
   - Політики retry/backoff і контроль timeout.
   - Стійка обробка мережевих збоїв та помилок виконання.
4. CLI
   - Зручні операторські команди для черги, агентів і результатів.
   - Поліпшений UX/валідація аргументів.
5. Acceptance/release
   - Acceptance-сценарії для Linux/Windows.
   - Release-чекліст для випуску v0.1.
